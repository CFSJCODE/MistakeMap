# Como citar o MistakeMap — ABNT

Este arquivo apresenta uma referência recomendada para o **MistakeMap** em trabalhos acadêmicos que adotam as normas da **ABNT**, especialmente a **NBR 6023:2018** para elaboração de referências.

> O painel nativo **Cite this repository** do GitHub gera automaticamente apenas formatos como APA e BibTeX. Por isso, a referência ABNT é disponibilizada separadamente neste arquivo.
