# MistakeMap 📍

Projeto Integrado I - Desenvolvimento Móvel (PUC Minas).

Aplicativo desenvolvido em Flutter para mapeamento e registro de ocorrências / apontamentos.

---

## 🚀 Estrutura do Projeto

- `appmistakemap/`: Código-fonte do aplicativo Flutter.
- `Documentação/`: Documentos de especificação, propostas e sprints (ignorado no repositório por padrão via `.gitignore`).

---

## 🛠️ Como Executar o Projeto

### Pré-requisitos
- [Flutter SDK](https://docs.flutter.dev/get-started/install) instalado e configurado.
- Um emulador configurado (Android/iOS) ou dispositivo físico conectado com depuração USB ativada.

### Passos

1. Acesse o diretório do aplicativo:
   ```bash
   cd appmistakemap
   ```

2. Obtenha as dependências:
   ```bash
   flutter pub get
   ```

3. Execute o aplicativo:
   ```bash
   flutter run
   ```
